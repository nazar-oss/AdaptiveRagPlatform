# Самостійна робота №2.3: Інтеграція LLM у проєкт (LLM API, function calling та prompt engineering)

## 1. Архітектура модуля
- **Провайдер та модель:** Cohere API (`command-a-03-2025`) через OpenAI-сумісний клієнт (`Microsoft.Extensions.AI.OpenAI` та `Microsoft.Agents.AI.OpenAI`).
- **Безпека ключів:** API-ключ збережено через `dotnet user-secrets` (`Ai:ApiKey`).
- **Структура модуля (`src/AdaptiveRag.Api/Ai/`):**
  - `StudyAssistant.cs` — двохетапна обробка звернення: структурована класифікація (`AnalyzeAsync` із валідацією JSON та retry-механізмом) і генерація відповіді з викликом функцій (`AnswerAsync`).
  - `PlatformTools.cs` — функція `get_material_info(materialId)` для отримання інформації про навчальний матеріал з бази даних (`AdaptiveRagDbContext`).
  - `PromptStore.cs` — завантаження версіонованих промптів (`v1`, `v2`, `v3`) та few-shot прикладів.
  - `PromptEvaluator.cs` — автоматичний бенчмарк на 10 тестових кейсах (`Tests/test-cases.json`).

## 3. Приклад роботи ендпоінту `POST /api/ai/assistant`

**Запит:**
```json
{
  "text": "Підкажи назву та статус індексації матеріалу 101"
}

```

**Відповідь:**
```json
{
  "attempts": 1,
  "answer": "Назва матеріалу 101: «Архітектура та патерни проєктування ПЗ».\nПредмет: Інженерія програмного забезпечення.\nСтатус індексації: індексовано.",
  "toolCalls": [
    "get_material_info(101)"
  ],
  "inputTokens": 295,
  "outputTokens": 50
}
```

## 4. Висновок
У ході виконання роботи я інтегрував LLM API Cohere у веб-API платформи `AdaptiveRagPlatform`, реалізував структурований вивід JSON із валідацією та механізмом повторного запиту, а також підключив інструмент `get_material_info` для безпечного отримання даних про навчальні матеріали з БД. Порівняння трьох версій промптів показало, що базовий промпт `v1` витрачає найменше токенів (155), проте помиляється у виклику інструменту (8/10). Деталізований промпт `v2` виправив виклик інструменту до 10/10, але припустився однієї помилки класифікації на межовому запиті (9/10). Найкращий результат показала версія `v3` із доданими few-shot прикладами — 10/10 за всіма критеріями якості (валідність JSON, точність категорії, виділення `material_id` та коректний виклик інструменту).
