# Безпека даних, конфіденційність та захист від prompt injection
Платформа AdaptiveRagPlatform обробляє навчальні матеріали та результати успішності студентів відповідно до вимог захисту персональних даних. Усі з'єднання між клієнтським застосунком і сервером шифруються за протоколом HTTPS (TLS 1.3), а паролі користувачів зберігаються у вигляді криптографічних гешів за алгоритмом Argon2id.

Окрему увагу приділено безпеці підсистеми штучного інтелекту:
- Ключі доступу до зовнішніх провайдерів LLM та моделей embeddings (Cohere, OpenAI) ніколи не зберігаються у вихідному коді чи Git-репозиторії; для локальної розробки використовується dotnet user-secrets, а на сервері — захищені змінні середовища.
- Інструменти виклику функцій (function calling), доступні мовній моделі, працюють виключно в режимі читання (read-only) і не мають прав на зміну оцінок, видалення курсів чи перегляд чужих облікових записів.
- Для захисту від атак типу prompt injection (коли користувач намагається змусити модель ігнорувати системні правила через текст запиту або приховані інструкції в документі) застосовується дворівнева ізоляція: системні інструкції відокремлені від даних користувача, а вихідні структури перевіряються суворою JSON-схемою.
