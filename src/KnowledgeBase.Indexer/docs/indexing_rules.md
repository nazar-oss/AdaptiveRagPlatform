# Регламент завантаження та індексації навчальних матеріалів
Для коректної роботи семантичного пошуку всі навчальні матеріали, що завантажуються на платформу AdaptiveRagPlatform, повинні відповідати технічним вимогам регламенту. Максимальний розмір одного файлу становить 25 мегабайт. Підтримуються формати PDF (із текстовим шаром), DOCX, TXT та Markdown у кодуванні UTF-8. Скановані зображення без розпізнаного тексту відхиляються на етапі валідації.

Після завантаження документа система присвоює йому числовий ідентифікатор (починаючи з 101) та встановлює початковий статус «У черзі» (Pending). Фоновій службі індексації потрібно від 15 до 90 секунд для розбиття тексту на фрагменти та генерації векторів. Після завершення обробки статус змінюється на «Індексовано» (Indexed), і матеріал стає доступним для AI-асистента та генератора тестів.

Якщо під час обробки виникає помилка (наприклад, файл захищений паролем, пошкоджена структура архіву або перевищено квоту API ембедингів), матеріал отримує статус «Помилка індексації» (Failed) із текстовим описом причини в журналі подій. Викладач може перезапустити індексацію кнопкою «Повторити обробку» після усунення проблеми. Перед індексацією система автоматично видаляє колонтитули, номери сторінок і дублікати порожніх рядків, зберігаючи заголовки розділів.
