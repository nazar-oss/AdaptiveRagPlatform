# Регламент завантаження та індексації навчальних матеріалів
Для коректної роботи семантичного пошуку всі навчальні матеріали, що завантажуються на платформу AdaptiveRagPlatform, повинні відповідати технічним вимогам цього регламенту. Максимальний розмір одного файлу становить 25 мегабайт, а сумарний обсяг матеріалів у межах однієї навчальної дисципліни не може перевищувати 500 мегабайт. Підтримуються формати PDF (обов'язково з вбудованим текстовим шаром), DOCX, TXT та Markdown у кодуванні UTF-8. Скановані зображення у форматі PDF без попереднього оптичного розпізнавання тексту (OCR) автоматично відхиляються на етапі первинної валідації.

Після успішного завантаження документа система присвоює йому унікальний числовий ідентифікатор (починаючи з 101), фіксує автора, дату завантаження та встановлює початковий статус «У черзі» (Pending). Фоновій службі індексації потрібно від 15 до 90 секунд залежно від обсягу тексту для нормалізації, розбиття тексту на фрагменти та пакетної генерації векторних представлень. Після завершення обробки статус змінюється на «Індексовано» (Indexed), і матеріал стає доступним для пошуку AI-асистентом та роботи генератора адаптивних тестів.

Якщо під час обробки виникає технічна або логічна помилка (наприклад, файл захищений паролем, пошкоджена XML-структура архіву DOCX, документ містить менше ніж 200 символів корисного тексту або перевищено квоту зовнішнього API ембедингів), матеріал отримує статус «Помилка індексації» (Failed) із детальним текстовим описом причини в журналі подій. Викладач може перезапустити обробку кнопкою «Повторити індексацію» після усунення проблеми без повторного завантаження файлу.

Перед розбиттям на чанки препроцесор системи автоматично очищує текст: видаляє повторювані колонтитули, номери сторінок, службові виноски та дублікати порожніх рядків, але обов'язково зберігає заголовки розділів і підрозділів, оскільки вони несуть ключовий тематичний контекст для векторного пошуку. При оновленні версії конспекту старі чанки документа повністю видаляються з бази перед записом нових, що виключає дублювання застарілої інформації.
