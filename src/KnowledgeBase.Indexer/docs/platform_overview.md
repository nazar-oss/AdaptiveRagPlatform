# Огляд освітньої платформи AdaptiveRagPlatform
AdaptiveRagPlatform — це інтелектуальна вебплатформа для автоматизованої обробки навчальних матеріалів, семантичного пошуку по конспектах та генерації адаптивних тестів для студентів вищих навчальних закладів і коледжів. Система поєднує класичне зберігання метаданих курсів у реляційній базі даних PostgreSQL із векторним індексуванням фрагментів тексту за технологією Retrieval-Augmented Generation (RAG).

Основна мета платформи полягає у зменшенні часу підготовки викладачів до модульного контролю та забезпеченні студентів персоналізованим тьютором, який відповідає виключно на основі перевірених лекційних матеріалів курсу без вигадування фактів (галюцинацій). Кожен навчальний документ проходить чотири стадії життєвого циклу: завантаження автором, очищення та нормалізація тексту, розбиття на змістові чанки та обчислення векторних ембедингів.

Платформа підтримує три ролі користувачів:
1. Студент — переглядає проіндексовані курси, ставить запитання AI-асистенту, проходить тренувальні та контрольні тести, подає апеляції на оцінювання відкритих відповідей.
2. Викладач — завантажує лекції та методичні вказівки у форматах PDF, DOCX та Markdown, перевіряє статус індексації матеріалів, затверджує згенеровані тестові завдання та розглядає апеляції студентів.
3. Адміністратор — керує обліковими записами, налаштовує ліміти токенів LLM, контролює стан черг індексації та резервне копіювання баз даних.
