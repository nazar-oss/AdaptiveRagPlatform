# Огляд освітньої платформи AdaptiveRagPlatform
AdaptiveRagPlatform — це інтелектуальна вебплатформа для автоматизованої обробки навчальних матеріалів, семантичного пошуку по конспектах та генерації адаптивних тестів для студентів вищих навчальних закладів і фахових коледжів. Система поєднує класичне зберігання метаданих курсів, груп та результатів оцінювання у реляційній базі даних PostgreSQL із векторним індексуванням фрагментів тексту за технологією Retrieval-Augmented Generation (RAG).

Основна мета платформи полягає у зменшенні часу підготовки викладачів до модульного і підсумкового контролю та забезпеченні студентів персоналізованим AI-тьютором, який відповідає виключно на основі перевірених лекційних матеріалів курсу без вигадування фактів (галюцинацій). Кожен навчальний документ проходить чотири обов'язкові стадії життєвого циклу: завантаження автором, очищення та нормалізація тексту, розбиття на змістові чанки та обчислення векторних ембедингів.

Платформа підтримує три основні ролі користувачів із розмежуванням прав доступу:
1. Студент — переглядає закріплені за його навчальною групою проіндексовані курси, ставить запитання AI-асистенту, проходить тренувальні та контрольні тести, переглядає детальні протоколи перевірки та подає апеляції на оцінювання відкритих відповідей.
2. Викладач — створює дисципліни, завантажує лекції та методичні вказівки у форматах PDF, DOCX, TXT та Markdown, контролює статус індексації матеріалів, затверджує або редагує згенеровані тестові завдання та розглядає апеляції студентів.
3. Адміністратор — керує обліковими записами користувачів, призначає ролі, налаштовує місячні й денні ліміти токенів LLM для факультетів, контролює стан фонових черг індексації та виконує резервне копіювання баз даних.

Архітектурно платформа складається з клієнтського SPA-застосунку (React + TypeScript), серверного REST API на базі .NET 10, фонового воркера індексації документів та векторного сховища. Усі відповіді AI-асистента супроводжуються інтерактивними посиланнями на конкретний файл конспекту та порядковий номер фрагмента, з якого взято інформацію, що дозволяє студенту миттєво перевірити першоджерело.
