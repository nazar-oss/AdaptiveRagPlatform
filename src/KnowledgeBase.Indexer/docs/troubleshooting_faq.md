# Поширені технічні несправності та інструкція з їх усунення (FAQ)
У цьому довідковому документі зібрано типові технічні проблеми, з якими стикаються студенти, викладачі та адміністратори під час роботи з платформою AdaptiveRagPlatform, а також покрокові способи їх швидкого самостійного вирішення без звернення до служби підтримки.

Помилка 429 (Too Many Requests) під час роботи AI-асистента або індексації:
Виникає при перевищенні ліміту запитів на хвилину для пробного (trial) API-ключа провайдера мовної моделі або сервісу ембедингів. Користувачеві рекомендується зачекати 60 секунд і повторити запит. Для адміністраторів у файлі конфігурації сервера передбачено спеціальний параметр DelayMs для регулювання паузи між пакетними запитами під час масового завантаження нових конспектів.

Помилка 500 (Internal Server Error) під час відкриття або збереження тесту:
Зазвичай спричинена короткочасною втратою з'єднання з сервером бази даних або завершенням часу дії токена авторизації. Оновіть сторінку з очищенням кешу (Ctrl+F5), виконайте повторний вхід в обліковий запис і перевірте стабільність інтернет-з'єднання. Прогрес відповідей студента під час тестування зберігається у локальному сховищі браузера та на сервері автоматично кожні 15 секунд, тому введені дані не втрачаються.

AI-асистент не знаходить інформацію за завантаженим матеріалом:
Відкрийте картку курсу та перевірте індикатор стану документа. Пошук виконується лише за тими матеріалами, які мають статус «Індексовано» (Indexed). Якщо файл щойно додано і він перебуває в статусі «У черзі» або завершився зі статусом «Помилка індексації» (наприклад, через відсутність текстового шару в PDF), фрагменти цього документа не потрапляють у векторну базу до моменту успішного завершення обробки.
